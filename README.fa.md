## چه می‌شود پرسید

- «با ۵ میلیون تومان چه هدفون بی‌سیمی بخرم؟»
- «کدام سرخ‌کن‌های بدون روغن بین ۳ تا ۶ میلیون تومان به کمترین قیمت یک ماه اخیرشان نزدیک‌ترند؟»
- «گلیم دستبافت زیر ۳ میلیون تومان می‌خواهم؛ به چه چیزهایی نگاه کنم؟»
- «این لینک دیجی‌کالاست؛ لینکی بده که کش‌بک بدهد.»

## ابزارها

هر چهار ابزار فقط‌خواندنی‌اند و annotations استاندارد MCP دارند (`readOnlyHint: true`). تعریف کامل با schema ورودی در [server card](https://pasavard.ir/.well-known/mcp/server-card.json) است.

| ابزار | کار | ورودی |
|---|---|---|
| `best_lists` | فهرست صفحه‌های «بهترین در هر بازه‌ی قیمت»، هر کدام یک دسته و یک بازه، با slug. نقطه‌ی شروع پرسش‌های «با این بودجه چه بخرم». | ندارد |
| `best_list` | کالاهای یک فهرست را به ترتیب نزدیکی قیمت امروز به کمترین قیمت ۳۰ روز اخیر همان کالا می‌چیند (قیمت ساعتی ثبت‌شده، نه درصد تخفیف اعلامی)، با `price_status`، `buy_url` و `cashback_url`. | `slug` |
| `search_products` | جست‌وجو در کاتالوگ رصدشده‌ی پس‌آورد (فقط کالای موجود، حداکثر ۱۰ نتیجه) با آخرین قیمت به تومان. جست‌وجوی همه‌ی فروشگاه نیست. | `query`، اختیاری `store` (‏`digikala` یا `snappshop`) |
| `buy_link` | برای هر آدرس کالا از دیجی‌کالا یا اسنپ‌شاپ (حتی بیرون از کاتالوگ) `buy_url` و `cashback_url` می‌سازد. فقط دامنه‌ی این دو فروشگاه پذیرفته می‌شود. | `url` |

## اتصال

**Claude Code**

```bash
claude mcp add --transport http pasavard https://pasavard.ir/api/mcp
```

**Claude Desktop** (فایل پیکربندی، با پل `mcp-remote`؛ یا Settings ← Connectors ← Add custom connector)

```json
{
  "mcpServers": {
    "pasavard": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://pasavard.ir/api/mcp"]
    }
  }
}
```

**Cursor**

```json
{
  "mcpServers": {
    "pasavard": {
      "url": "https://pasavard.ir/api/mcp"
    }
  }
}
```

## افشای افیلیت و کش‌بک

درآمد پس‌آورد از پورسانت [افیلیو](https://affilio.ir) (شبکه‌ی همکاری در فروش دیجی‌کالا و اسنپ‌شاپ) است. **هر لینک خریدی که این سرور برمی‌گرداند افیلیت است** و قیمت برای خریدار فرقی نمی‌کند. اولین خط هر نتیجه‌ی ابزار همین را می‌گوید.

برای هر کالا دو لینک برمی‌گردد:

- `buy_url`: مستقیم به فروشگاه می‌رود؛ ورود لازم نیست و پورسانت کامل برای پس‌آورد است.
- `cashback_url`: بعد از یک بار ورود با شماره‌ی موبایل در pasavard.ir، **۵۰٪ پورسانت** آن خرید به‌صورت کش‌بک به خود خریدار می‌رسد (قاعده‌ها در [pasavard.ir/rules](https://pasavard.ir/rules)). وقتی کاربر قصد خرید دارد این لینک را پیشنهاد کنید.

کالاهای «شگفت‌انگیز» دیجی‌کالا پورسانت ندارند و با `cashback: false` مشخص می‌شوند.

## داده

- کاتالوگ: فهرست کالاها از API عمومی افیلیو برای دیجی‌کالا و اسنپ‌شاپ.
- قیمت: هر ساعت دوباره ثبت می‌شود؛ کمترین قیمت ۳۰ روز و رتبه‌بندی از تاریخچه‌ی قیمت خود پس‌آورد محاسبه می‌شود، نه از قیمت پایه‌ی فروشگاه.
- قیمت‌ها به تومان‌اند، آخرین قیمت ثبت‌شده‌اند و ممکن است تا لحظه‌ی خرید عوض شوند؛ پیش از پرداخت در فروشگاه کنترل کنید.

## محدودیت‌ها

- ۶۰ درخواست در دقیقه برای هر IP و ۱۲۰ در دقیقه برای کل کاربران؛ بیشتر از آن پاسخ ۴۲۹ با `Retry-After: 60` است.
- بدنه‌ی درخواست تا ۶۴ کیلوبایت؛ `search_products` حداکثر ۱۰ و `best_list` حداکثر ۱۵ کالا برمی‌گرداند.

## حریم خصوصی و ایمنی

- فقط‌خواندنی و بدون احراز هویت: هیچ ابزاری چیزی را تغییر نمی‌دهد و سرور از طریق MCP اطلاعات شخصی نمی‌خواهد.
- `buy_link` آدرس را با دو دامنه‌ی فروشگاه می‌سنجد و درخواست بیرونی نمی‌فرستد.
- باز کردن `buy_url` یا `cashback_url` یک کلیک روی pasavard.ir ثبت می‌کند (برای انتساب)، مثل هر لینک افیلیت.
